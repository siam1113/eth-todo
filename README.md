# Ethereum Todo List

A blockchain-based todo list application. Todo items are stored and managed through a smart contract deployed on the Ethereum network.

## Stack

- Solidity (smart contracts)
- Truffle (compilation, migration, testing)
- Web3.js

## Layout

```text
contracts/      Solidity smart contracts
migrations/     Truffle migration scripts
test/           Contract tests
```

## Getting Started

```bash
npm install
truffle compile
truffle migrate
npm run dev
```

## Running Tests

```bash
truffle test
```
